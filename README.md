# Parker Home

Personal website and classical music collection built with VitePress.

## About

This is my personal website for organizing and presenting information about classical music, recordings, albums, composers, works, instruments, and related metadata.

The site is built as a static website with VitePress and Vue.

## Features

- Personal homepage
- Classical music collection
- Album and recording information
- Composer and work metadata
- Instrument information
- Multilingual support
- Custom Vue components
- Responsive design

## Tech Stack

- [VitePress](https://vitepress.dev/)
- [Vue](https://vuejs.org/)
- TypeScript
- Markdown
- CSS

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run docs:dev
```

Build the website:

```bash
npm run docs:build
```

Preview the production build:

```bash
npm run docs:preview
```
